# ありみち — アリが描く終わらない模様

右か左に曲がるだけのアリが、歩くたびにマスの色を変えて模様を描く。曲がり方のルールを変えると、渦・左右対称・三角など、まったく違う形が育つ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/arimichi/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

もとは「ラングトンのアリ（Langton's ant）」という数学のしくみ。

1. アリは今いるマスの色を見て、決まった向きに曲がる。マスの色を次の色に変えて、1 マス進む。これをくり返す。
2. 下のルールの札をタップすると曲がり方が変わる（右・左・直・戻）。札を足すと色が増える（2〜12 色）。
3. 盤をタップするとアリが増える（8 匹まで）。「見本」から有名な模様も選べる。

- 「▶ / ⏸」で動かす・止める、「1 歩」で 1 歩だけ進める、「はじめから」で盤を消す。速さは 4 段階。
- PC では Space で動かす・止める、→ で 1 歩。
- 盤は 160 × 160 マスで、上下・左右の端はつながっている。
- 共有すると、今のルールが URL（`?r=LLRR` など）に入る。その URL を開くと同じルールで始まる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

テスト（Node.js、フレームワークなし）:

```sh
node test.mjs
```

| ファイル | 中身 |
|---|---|
| `ant.js` | 中身（盤・アリの 1 歩・ルール文字列・保存と URL の読み書き・見本）。DOM に触らない |
| `main.js` | 画面と操作・描画 |
| `test.mjs` | `ant.js` のテスト |

- 盤は 1 マス = 1 点の Canvas を CSS で拡大して描く。1 フレームで変わったマスの範囲だけを書き直す。
- 1 フレームで進める歩数は 2,000 歩まで（いちばん速いときでも画面が固まらないように）。
- 保存は `arimichi.state`（`{ v: 1, rule, speed, seenHelp }`）。盤とアリは保存しない。
